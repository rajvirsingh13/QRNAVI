Free QR Code Generator FAQ

Answers to common questions about creating and using QR codes with QRNAVI.

What is a QR code?

A QR code is a two-dimensional code that can store information such as a website URL, text, contact information or other supported data.

Can I create a QR code for a website?

Yes. Select the URL QR code option and enter the website address you want to encode.

Can I create a WiFi QR code?

Yes. QRNAVI includes a WiFi QR code generator for supported wireless network information.

Can I create a QR code for text?

Yes. Select Text and enter the information you want to encode into the QR code.

Can I create a QR code for contact information?

Yes. QRNAVI supports Contact / vCard QR codes for supported contact information.

Can I customize my QR code?

Yes. After generating a QR code, the Customize option will open the separate QRNAVI customization editor.

Can I download my QR code?

Yes. After generating a QR code, the Download option can be used to save the generated QR image.

Can QRNAVI scan QR codes?

Yes. QRNAVI includes a dedicated QR Code Scanner page for supported devices and browsers.
